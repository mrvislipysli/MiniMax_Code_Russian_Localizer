# MiniMax Russian Localizers

Данный репозиторий содержит неофициальные русификаторы для приложений от компании MiniMax: **MiniMax Code** (IDE) и **MiniMax Design** (редактор).

## 📂 Структура проекта

* `MiniMax_Code/` — русификатор для **MiniMax Code**
* `MiniMax_Design/` — русификатор для **MiniMax Design**

## 🚀 Как установить русификаторы

Для каждого из приложений есть отдельный скрипт-установщик.

1. Перейдите на вкладку [Releases](https://github.com/mrvislipysli/MiniMax_Code_Russian_Localizer/releases) (или скомпилируйте `exe` самостоятельно, см. ниже).
2. Скачайте нужный установщик: `MiniMax_Localizer.exe` для Code или `MiniMax_Design_Localizer.exe` для Design.
3. Убедитесь, что само приложение (MiniMax Code / Design) **закрыто**.
4. Запустите скачанный `.exe` файл от имени администратора. 
5. Скрипт автоматически найдет установленное приложение, извлечет ресурсы, добавит русский язык и переупакует всё обратно.
6. Откройте приложение, перейдите в **Settings -> Language** и выберите **Русский**.

## 🛠 Самостоятельная сборка (для разработчиков)

Если вы хотите собрать `.exe` файлы самостоятельно:

### Требования
* Установленный Node.js (рекомендуется v18+)
* Утилита `pkg` для компиляции

### Сборка MiniMax Code
```bash
cd MiniMax_Code
npm install
npm run build
```
Исполняемый файл появится в папке `dist`.

### Сборка MiniMax Design
```bash
cd MiniMax_Design
npm install
npm run build
```
Исполняемый файл появится в папке `dist`.

## ⚙️ Как это работает?
Оба скрипта работают по схожему принципу:
1. Завершают процесс приложения (если он запущен).
2. Находят архив `app.asar` в директории `AppData\Local\com.minimax.hub.global\current\resources` (или `Programs\MiniMax Code\resources`).
3. Распаковывают `app.asar` с помощью `@electron/asar`.
4. Патчат минифицированные JS-файлы интерфейса, внедряя переведенные словари (из папки `locales`) и добавляя пункт «Русский» в настройки.
5. Запаковывают измененные файлы обратно в `app.asar`.

---
*Словари переведены с использованием нейросетевого перевода на основе оригинальных файлов локализации.*
